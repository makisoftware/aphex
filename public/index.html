Tutorial Guide

1. Pulleys & String Wrap STEP 1

A string wraps taut around circular pulleys along outer tangents. Toggle IN (CW) vs OUT (CCW) on each pulley card to create convex arcs, concave waistlines, loops, and figure-8 crossovers.

Tip: Moving a pulley inside or across other pulleys can cause tangent crossovers where the wrap direction needs to change. It is up to you to flip between IN and OUT to resolve tangles or create concave contours!

2. Groups & Boolean Holes STEP 2

Create multiple independent pulley shapes with + GROUP. Toggle a group to - HOLE to cut crisp vector holes through any shapes beneath it.

3. Multi-Selection & Rescaling STEP 3

Hold Shift / Cmd + click or drag a marquee box on empty canvas to select multiple pulleys. Drag to move them in sync, or drag the corner bounding box handles to scale positions and radii proportionally.

4. Precision Snapping & Nudge STEP 4

Pulleys automatically snap to grid lines (20px/40px), cell midpoints, and center/edge alignments with other pulleys. Use the Arrow Keys (↑↓←→) to nudge selections with sub-pixel control.

5. SVG Vector Export & JSON Save STEP 5

Type a custom name in the FILE box. Export SVG generates production-ready vector graphics with native hole masks, ready for Figma, Illustrator, or web usage.
